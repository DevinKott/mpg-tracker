MPGT-005 | UX | Medium
Disabled Save button provides no explanation to the user

---

DESCRIPTION
In AddEntryView, the Save button is disabled when required fields are empty or
invalid, but no message tells the user why. The user sees a greyed-out button
with no indication of which field needs attention or what the issue is.

AFFECTED FILE
MPGTracker/Views/Entry/AddEntryView.swift

ACCEPTANCE CRITERIA
- [ ] When the Save button is disabled, the user can identify which field(s)
      are preventing the save (e.g., inline hint, highlighted field border, or
      a short message near the button).
- [ ] The hint disappears once the field is valid.
- [ ] No change to behavior when all fields are valid — the button enables normally.

SUGGESTED FIX
Add a short contextual message near the Save button (e.g., "Miles and gallons
are required") that is only visible while the button is disabled. Alternatively,
highlight the empty required fields with a warning color as a visual cue.
