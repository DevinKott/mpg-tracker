MPGT-002 | UX | High
Price-per-gallon override field has no visual affordance

---

DESCRIPTION
The calculated price-per-gallon value in AddEntryView looks like a read-only
label but is actually tappable to enter manual edit mode. There is no visual
indicator that it is interactive. Users will not discover the override feature,
and those who do may trigger it unintentionally.

AFFECTED FILE
MPGTracker/Views/Entry/AddEntryView.swift

ACCEPTANCE CRITERIA
- [ ] The PPG field is visually distinct from static labels (e.g., styled as a
      tappable row or shows an edit icon).
- [ ] A brief label or caption indicates the field is calculated but can be
      overridden (e.g., "Calculated — tap to override").
- [ ] Entering edit mode is clearly reversible and the "Use calculated" action
      is prominently accessible.

SUGGESTED FIX
Add a small pencil icon or "Edit" label next to the calculated PPG value to
signal interactivity. Alternatively, replace the tap-to-edit pattern with a
visible toggle ("Override") that expands the editable field when switched on.
